# Homestay2U Malaysia

A Flutter mobile application that retrieves and displays homestay information from a REST API.

## Features
- View homestay listings
- Search homestays
- Filter by state
- Filter by district
- Pull-to-refresh
- Homestay detail page
- Loading indicators
- Error handling

## Technologies Used
- Flutter
- Dart
- REST API
- HTTP Package
